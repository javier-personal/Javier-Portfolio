(Each month reflects a project phase, from user requirements to deployment)

Date Description Ref No. Phase Details
01 Mar 2025 Requirement Gathering with Stakeholders REF001 Requirement

Requirement Gathering & Business Understanding

Held calls and workshops with stakeholders to understand department operations, SLA tracking, channel performance and key metrics. Agreed the scope, reports, visuals and acceptance criteria, and used PowerPoint mockups to gather feedback before building.

01 Apr 2025 Preliminary Analysis REF002 Data Analysis

Preliminary Analysis

Profiled sample data in Excel to find missing values, inconsistencies and formatting issues, and shared the findings with stakeholders. These shaped the cleansing needed before ingestion and the SQL view logic.

01 May 2025 Hive SQL View Developed REF003 SQL

SQL View Logic

Iterated with users to confirm the data, columns and transformations required, then translated the business logic into Hive SQL views (using CTEs) that drive the dashboard.
01 June 2025 Dashboard Visual Completed REF004 Dashboard

Finalized Dashboard

Once the views were signed off, connected Power BI to the Hive/Hue data with Power Query M and imported it into the .pbix file. Built the visuals with DAX and Query M, and verified the design and logic with users before deployment.
01 July 2025 User Testing Phase REF005 Testing

User Testing & Feedback

Users tested the dashboard for data accuracy, business logic and visuals. Feedback was applied iteratively to the transformations, SQL views and visuals, and metrics were validated by comparing Excel and SQL outputs against source data.

01 August 2025 Deployment & Maintenance REF006 Deployment

Deployment & Maintenance

After user sign-off, prepared the production artefacts: finalised SQL views, Power BI reports and documentation. Ongoing maintenance and support were planned for new requirements and consistent data quality.
