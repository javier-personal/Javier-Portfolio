Data Visualization & Analytics

Performed cleaning, transformation, clustering, and regression analysis using KNIME, and built Power BI dashboards to uncover customer behavior and insights.

My contribution

Cleaned and transformed the data in KNIME, formed four K-Means clusters, trained a linear regression model to predict customer ratings for restaurants. Created Power BI dashboards to visualise model residuals, assess model fit & develop analytical visuals to support data-driven decision-making.

Tools

  • KNIME
  • Power BI
  • K-Means
  • Linear regression

Strongest documented result

The linear regression model predicting restaurant ratings reached an R² of 0.823 with a mean absolute error of 0.116.
